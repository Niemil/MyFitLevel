# For other sites and developers

Open data and notes from MyFitLevel (AGPL-3.0), meant for anyone building a compatible logger or integration (for example snakediet.org).

- `logger-spec.md`: how the workout logger works (screens, data model, point formulas, where the code is).
- `exercises.json` / `exercises.csv`: the built-in exercise library (name, muscle, equipment, kind, point coefficients).
- Live API guide: https://myfitlevel.com/api-docs. Live version check: https://myfitlevel.com/api/v1/ping

Nothing here contains secrets, keys or user data.
